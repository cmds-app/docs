# DataGrip

JetBrains' database IDE, for working with the CMDS databases directly: SQL Server on the Prism side and PostgreSQL on the Vesper side.

## Getting started

- Add a data source for each database. DataGrip ships the SQL Server and PostgreSQL drivers.
- Point each connection at your local development database. Connection details live in the app's `appsettings.work.json`, which is untracked.
- Use it to browse tables, run the schema and migration SQL, and inspect query results while developing.
