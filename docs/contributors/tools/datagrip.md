# DataGrip

JetBrains' database IDE, for working with the CMDS PostgreSQL database directly.

## Getting started

- Add a PostgreSQL data source. DataGrip ships the driver.
- Point the connection at your local development database. Connection details live in the app's `appsettings.work.json`, which is untracked.
- Use it to browse tables, run the schema and migration SQL, and inspect query results while developing.
