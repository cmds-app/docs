# Visual Studio Code

The editor for all CMDS development work: the .NET API and command-line tool, the Vite + React SPA, and this documentation site.

## Recommended extensions

- **C# Dev Kit** - C# and .NET support, including building, debugging, and running the tests, for the API and the command-line tool.
- **ESLint** and **Prettier** - linting and formatting for the SPA, using the configuration already in the repository.
- **Tailwind CSS IntelliSense** - class name completion for the SPA's styles.
